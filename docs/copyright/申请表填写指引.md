## 三、软件功能与技术特点

此栏为文字描述，通常限 300–1000 字。以下为可直接采用的稿件，与用户手册第 1 章一致。

### 3.1 软件功能（建议稿）

> 本软件是面向计算机视觉与机器学习方向研究人员的学术文献精读工具，采用前后端分离架构，后端基于 Python 与 FastAPI 框架实现，前端基于 TypeScript 与 React 框架实现，数据存储于本地 SQLite 数据库。
>
> 软件主要功能包括七个模块。一是论文解析模块，接收用户上传的 PDF 论文，抽取正文文本并调用大语言模型完成结构化解析，输出核心贡献、研究问题、论文大纲、方法论、实验设置、代码映射与问答测验七类结构化内容，解析在后台异步执行并通过事件流实时推送进度。二是论文阅读模块，提供原文渲染与解析结果的双栏对照阅读界面，支持章节跳转、页面缩放、专注模式，以及选中文本后的即时翻译、摘要生成与多色标注。三是论文库管理模块，提供分页浏览、关键词与语义检索、多维筛选排序、批量操作与元数据重新提取。四是代码仓库分析模块，自动识别论文中的代码仓库地址，克隆后构建文件树、静态解析引用依赖，并分析数据流走向与论文概念到代码实现的对应关系。五是工作区管理模块，按研究主题将论文组织为集合。六是深度研究模块，在论文集合上执行研究流水线，完成全文收集、参考文献解析、联网扩展、文本分块与向量化、引文图谱构建与研究子方向划分，产出可交互的图谱视图与跨论文检索问答能力。七是系统设置模块，配置模型接入参数、界面主题与深度研究流程参数。

### 3.2 技术特点（建议稿）

> 本软件的技术特点体现在四个方面。
>
> 第一，结构化解析。软件不生成压缩式摘要，而是按学术论文的固有结构将内容拆解为方法流程、关键模块、数据集、基线方法、实验结果表格等独立字段，每个字段可单独查看并回溯到原文位置。
>
> 第二，解析过程与页面浏览解耦。论文解析以后台任务方式运行，前端仅作为事件订阅方，用户关闭页面或切换路由不会中断解析，重新进入时回放已缓冲的进度事件并继续接收后续进度，无需重新发起解析。
>
> 第三，统一的论文关联度度量与自监督权重校准。论文之间的关系强度由单一算法给出：从主题向量、研究目的、方法、术语重叠、共享数据集、共享基线、文献耦合、共被引八个通道分别计算相似度，各通道经分位数归一化后加权融合为一个分数，该分数同时决定图谱连边、社区划分、节点重要性与检索排序。由于各通道的判别力随语料而变，软件在建图时以论文集合自身的引用结构作为弱标签，度量每个语义通道的实际判别力并据此重新分配权重，再按证据量向先验权重收缩；证据不足或判别力与随机无异的通道保持先验值不变。
>
> 第四，基于目标密度的图谱控制。图谱骨架的密度参数是「目标平均度」，即每篇论文平均连出的边数，软件二分求解关联度阈值以逼近该目标，再执行显著性检验保留局部显著的边，使密度控制与打分尺度无关。

## 五、鉴别材料上传

| 材料 | 文件 | 生成方式 |
|------|------|----------|
| 源程序 | `build/源程序.docx` | `python3 docs/copyright/tools/gen_source_doc.py` |

生成命令需带上最终确定的名称、版本号与著作权人：

```
python3 docs/copyright/tools/gen_source_doc.py \
    --name "论文精读辅助分析软件" --version "V1.0"

python3 docs/copyright/tools/gen_manual_docx.py \
    --name "论文精读辅助分析软件" --version "V1.0" \
    --owner "著作权人姓名或单位全称"
```

## 六、职务作品判断

**【需你确认】**

若本项目属于以下任一情形，著作权人应填**单位**而非个人：

- 在校期间使用学校资源完成，或属于导师课题的组成部分
- 在职期间属于本职工作任务，或主要使用了单位的物质技术条件
- 有约定归属单位的协议

填错主体会导致证书权利人错误，且不便更正。若存在任何不确定，建议先与所在单位或学校的科研管理部门确认后再提交。

## 七、常见补正原因

以下均为形式问题，事前核对即可避免：

| 补正原因 | 预防措施 |
|----------|----------|
| 软件名称在申请表与鉴别材料中不一致 | 名称只从一处取值，用脚本的 `--name` 参数统一注入 |
| 版本号不一致 | 同上，用 `--version` 参数统一注入 |
| 著作权人与身份证明文件不符 | 单位名称须与营业执照完全一致，不使用简称 |
| 源程序每页不足 50 行 | 脚本按固定 50 行/页硬分页，不依赖 Word 自动断页 |
| 源程序页码缺失或不在右上角 | 脚本已在页眉右侧插入自动页码域 |
| 用户手册缺少界面截图 | 有操作界面的软件必须含操作步骤截图，见附录 C 的 37 项清单 |
| 用户手册每页不足 30 行 | 正文按 15 磅行距排版；含图页面可豁免 |
| 材料双面打印 | 纸质提交须单面打印 |
| 源程序或文档含接口密钥等敏感信息 | 提交前全文检索一次；截图中密钥字段保持掩码 |
