# 第 1 章 软件概述

## 1.1 软件简介

论文精读辅助分析软件是一套面向计算机视觉与机器学习方向研究人员的学术文献精读工具。用户上传 PDF 格式的学术论文后，软件自动完成文本抽取、结构化解析与要点归纳，把一篇非结构化的论文转换为可检索、可跳转、可追溯的结构化阅读材料。

软件采用前后端分离架构：后端以 Python 语言基于 FastAPI 框架实现，负责文档解析、模型调用、数据持久化与检索计算；前端以 TypeScript 语言基于 React 框架实现，负责界面呈现与交互。两端通过 HTTP 接口与 SSE（Server-Sent Events）事件流通信，全部数据存储于本地 SQLite 数据库与本地文件系统，无需依赖外部服务器。

软件在单篇论文精读之外，进一步提供跨论文的研究能力：用户可将同一研究方向的多篇论文组织为「工作区」，在工作区上运行「深度研究」流程，自动构建论文之间的引文图谱与关联度网络，并基于向量检索完成跨论文的问答。

## 1.2 主要功能

软件的功能划分为七个模块：

**（一）论文解析模块**

接收用户上传的 PDF 文件，抽取正文文本，调用大语言模型完成结构化解析，输出核心贡献、研究问题、论文大纲、方法论、实验设置、代码映射与问答测验七类结构化内容。解析过程在后台异步执行，前端通过事件流实时显示进度。

**（二）论文阅读模块**

提供 PDF 原文渲染视图与解析结果面板的双栏对照阅读界面。支持按章节跳转、页面缩放、专注模式全屏阅读。用户在原文中选中任意文本段落后，可就地发起翻译或摘要生成，也可添加荧光笔、下划线、删除线等标注。

**（三）论文库管理模块**

集中管理已上传的全部论文，提供分页浏览、关键词检索、语义检索、按领域与年份筛选、多种排序方式、批量删除与批量归入工作区等操作，并支持对全库论文重新提取元数据。

**（四）代码仓库分析模块**

从论文正文中自动识别代码仓库地址，克隆仓库到本地后构建文件树，静态解析各源文件之间的引用依赖关系，并调用模型分析仓库的数据流走向以及论文概念与代码实现之间的对应关系。模块内置代码浏览器与终端面板。

**（五）工作区管理模块**

按研究主题把论文组织为集合。一篇论文可同时属于多个工作区。工作区是深度研究模块的输入单元。

**（六）深度研究模块**

在工作区的论文集合上执行研究流水线：下载缺失的论文全文、解析参考文献、按需联网扩展相关文献、对全文分块并计算向量表示、构建引文图谱、抽取图谱骨架并划分研究子方向。产出的图谱在前端以可交互的力导向图呈现，同时提供跨论文的检索问答功能。

**（七）系统设置模块**

配置解读模型与翻译模型的接入参数、界面主题与字体、深度研究流程的各项参数，并提供模型连通性测试。

## 1.3 技术特点

**结构化解析而非摘要生成。** 软件不是把论文压缩成一段摘要，而是按研究论文的固有结构拆解为方法流程、关键模块、数据集、基线方法、实验结果表格等字段，每个字段可独立查看并回溯到原文位置。

**解析过程与页面浏览解耦。** 论文解析在后端以后台任务方式运行，前端仅作为事件订阅方。用户关闭页面或切换路由不会中断解析；重新进入页面时会回放已缓冲的进度事件并继续接收后续进度，无需重新发起解析。

**统一的论文关联度度量。** 深度研究模块中论文之间的关系强度由单一算法给出：从主题向量、研究目的、方法、术语重叠、共享数据集、共享基线、文献耦合、共被引八个通道分别计算相似度，各通道经分位数归一化后加权融合为一个分数。该分数同时决定图谱的连边、社区划分、节点重要性与检索排序。

**通道权重的自监督校准。** 各通道的判别力随语料而变。软件在建图时以工作区自身的引用结构（直接引用关系与文献耦合关系）作为弱标签，度量每个语义通道的实际判别力，据此重新分配权重，并按证据量向先验权重收缩。证据不足或判别力与随机无异的通道保持先验值不变。

**基于目标密度的图谱控制。** 图谱骨架的密度旋钮是「目标平均度」，即每篇论文平均连出的边数。软件二分求解关联度阈值以逼近该目标，再执行显著性检验保留局部显著的边。密度控制与打分尺度无关。

**本地优先的数据存放。** 论文原文、解析结果、标注笔记、向量索引与图谱数据全部保存在本地，模型调用地址与密钥由用户自行配置。

## 1.4 适用对象

本软件面向需要系统性阅读学术文献的人员，包括高等院校计算机及相关专业的研究生、科研院所研究人员、企业研发人员。使用者应具备基本的计算机操作能力，了解命令行的基本使用方法。

## 1.5 术语说明

| 术语 | 说明 |
|------|------|
| 精读 | 对单篇论文执行完整的结构化解析，产出全部七类结构化内容 |
| 速读 | 轻量级解析，仅抽取研究目的、方法、数据集、基线与简短总结，供图谱建立关系使用 |
| 工作区 | 按研究主题组织的论文集合，是深度研究的输入单元 |
| 深度研究 | 在工作区上运行的跨论文分析流程，产出引文图谱与向量索引 |
| 引文图谱 | 以论文为节点、以论文间关系为边的网络结构 |
| 论文关联度 | 衡量两篇论文相关程度的综合分数，由八个通道加权融合得出 |
| 骨架提取 | 从全连接的关联度矩阵中筛选出显著边，得到稀疏可读图谱的过程 |
| 目标平均度 | 图谱密度的控制参数，表示每篇论文平均连接的边数 |
| 子方向 | 图谱社区划分的结果，表示工作区内部的研究分支 |
| RAG 问答 | 检索增强生成，先检索相关文本片段再据此生成回答的问答方式 |
| 扩展论文 | 深度研究联网抓取到的、原本不在论文库中的相关文献 |
| SSE | Server-Sent Events，服务器向浏览器单向推送事件的通信机制 |
| GROBID | 用于解析学术文献结构与参考文献的开源工具 |

# 第 2 章 运行环境

## 2.1 硬件环境

| 项目 | 最低配置 | 推荐配置 |
|------|----------|----------|
| 处理器 | 双核 2.0 GHz | 四核 2.5 GHz 及以上 |
| 内存 | 4 GB | 16 GB 及以上 |
| 硬盘可用空间 | 2 GB | 20 GB 及以上 |
| 显卡 | 无要求 | 支持 CUDA 的独立显卡（仅本地向量模型需要） |

说明：内存与硬盘的推荐配置针对深度研究模块。该模块在本地向量化模式下需要加载嵌入模型（约 2 GB），并为每个工作区存储向量索引与论文全文。仅使用单篇论文精读功能时，最低配置即可满足。

## 2.2 软件环境

| 项目 | 要求 |
|------|------|
| 操作系统 | Linux、macOS 或 Windows |
| Python | 3.10 及以上版本 |
| Node.js | 18 及以上版本 |
| 浏览器 | Chrome、Edge、Firefox 或 Safari 的近两年版本 |
| 数据库 | SQLite（随 Python 标准库提供，无需单独安装） |

## 2.3 网络要求

软件本身在本地运行，界面访问不依赖外部网络。以下功能需要网络连接：

- 论文结构化解析、文本翻译、摘要生成：需访问用户配置的大语言模型服务地址
- 相关论文推荐：需访问学术文献检索服务
- 深度研究的联网扩展阶段：需访问文献元数据服务与论文托管站点
- 代码仓库分析：需访问代码托管平台以克隆仓库

深度研究模块可配置为「本地（不联网）」模式，此时联网扩展阶段被跳过，图谱仅基于工作区内已上传的论文构建。

# 第 3 章 安装与部署

## 3.1 获取程序

将软件的完整源程序目录复制到本机任意路径。以下操作均以该目录为当前工作目录，文中记为「项目根目录」。

## 3.2 配置环境变量

复制项目根目录下的环境变量样例文件，并填入模型服务的接入参数：

```
cp .env.example .env
```

用文本编辑器打开 `.env` 文件，至少填写以下三项：

```
LLM_API_KEY=用户申请的接口密钥
LLM_BASE_URL=模型服务地址
LLM_MODEL=模型名称
```

参数说明：

| 变量名 | 是否必填 | 说明 |
|--------|----------|------|
| `LLM_API_KEY` | 必填 | 模型服务的接口密钥 |
| `LLM_BASE_URL` | 选填 | 模型服务地址。地址中包含 `anthropic` 时按 Anthropic 消息协议调用，否则按 OpenAI 对话补全协议调用 |
| `LLM_MODEL` | 选填 | 模型名称 |
| `DATABASE_URL` | 选填 | 数据库文件路径，默认 `sqlite:///./data/essay_read.db` |
| `UPLOAD_DIR` | 选填 | 上传文件存放目录，默认 `./uploads` |
| `HOST` | 选填 | 后端监听地址，默认 `0.0.0.0` |
| `PORT` | 选填 | 后端监听端口，默认 `8000` |
| `FRONTEND_ORIGIN` | 选填 | 前端访问地址，用于跨域许可，默认 `http://localhost:5173` |

以上参数也可在软件启动后通过「设置」页面配置，两种方式等效。通过设置页面保存的配置写入 `data/ai_config.json` 文件。

## 3.3 安装后端依赖

在项目根目录创建并激活 Python 虚拟环境，随后安装后端依赖：

```
python3.10 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
cd backend
pip install -r requirements.txt
```

Windows 系统下激活虚拟环境的命令为 `.venv\Scripts\activate`。

## 3.4 安装前端依赖

```
cd frontend
npm install
```

## 3.5 一键启动

项目根目录提供启动脚本，依次完成端口检查、后端启动、前端启动与健康检查：

```
./start.sh
```

脚本默认使用 8000 端口运行后端、5173 端口运行前端。若端口已被占用，脚本会提示占用情况并终止启动。

【截图 3-1】启动脚本执行完成后的终端输出，显示后端与前端均已就绪。

## 3.6 分别启动

需要单独控制前后端时，可分别在两个终端窗口中执行。

启动后端：

```
cd backend
source ../.venv/bin/activate
python -m backend
```

或使用开发模式（代码变更时自动重载）：

```
uvicorn main:app --reload --port 8000
```

启动前端：

```
cd frontend
npm run dev
```

## 3.7 容器化部署

项目根目录提供 `docker-compose.yml` 编排文件。在已安装容器运行环境的机器上，可直接执行：

```
docker compose up -d
```

浏览器访问 `http://localhost:5173`。页面正常显示首页，且首页统计区能够读出论文数量与工作区数量，即表示前后端连通、数据库初始化成功。

后端接口文档位于 `http://localhost:8000/docs`，可用于确认后端服务状态。

# 第 4 章 快速开始

本章以一条完整路径演示软件的基本使用流程：配置模型 → 上传论文 → 查看解析结果。

## 4.1 配置解读模型

首次使用需先配置模型接入参数，否则论文解析功能不可用。

**操作步骤：**

1. 点击顶部导航栏的「设置」，进入设置页面
2. 停留在默认的「模型配置」选项卡
3. 在「解读模型」区域依次填写接口地址、接口密钥与模型名称
4. 点击「测试连接」按钮，确认返回成功
5. 在「翻译模型」区域填写同样的三项参数（可与解读模型使用同一套配置）
6. 点击页面底部的「保存配置」按钮

配置不完整时，设置页面顶部会显示提示条，明确指出是解读模型还是翻译模型缺少接口密钥。

【截图 4-1】设置页面「模型配置」选项卡，已填写完整参数。

## 4.2 上传论文

**操作步骤：**

1. 点击顶部导航栏的「入口」返回首页
2. 将 PDF 文件拖拽到首页下方的投放区，或点击投放区打开文件选择对话框
3. 投放区显示上传进度百分比
4. 上传完成后，软件自动跳转到论文精读页面，并自动开始解析

【截图 4-2】首页投放区正在上传文件，显示进度条。

## 4.3 查看解析进度

跳转到精读页面后，右侧分析面板显示解析进度。解析按阶段推进，进度信息实时更新。

此时可以：

- 在左侧 PDF 区域先行阅读原文，解析在后台继续
- 切换到其他页面，解析不会中断
- 关闭浏览器标签页，解析仍在后端继续执行

重新进入该论文的精读页面时，软件会回放已完成的进度并继续接收后续事件。

【截图 4-3】精读页面右侧面板显示解析进度。

## 4.4 阅读解析结果

解析完成后，右侧面板显示七个选项卡。点击各选项卡查看对应内容：

| 选项卡 | 内容 |
|--------|------|
| 概览 | 核心一句、研究问题、核心贡献、相关论文推荐 |
| 大纲 | 论文章节结构，点击可跳转到原文对应位置 |
| 方法 | 方法总览、流程图、详细步骤、关键模块表 |
| 实验 | 数据集、基线方法、主要结论、图表分析、消融实验 |
| 代码 | 论文中的代码仓库地址与代码分析入口 |
| Q&A | 基于论文内容生成的问答测验 |
| 笔记 | 用户对该论文的笔记 |

【截图 4-4】解析完成后的精读页面，右侧显示「概览」选项卡内容。

# 第 5 章 论文上传与精读

## 5.1 首页

首页是软件的入口，路径为 `/`。页面自上而下分为四个区域。

**标题与投放区。** 页面上半部分为标题区，下方横贯整条底边的区域为文件投放区。投放区支持拖拽投放与点击选择两种方式，仅接受 PDF 格式文件。上传过程中显示进度百分比；上传失败时在投放区下方显示错误提示。

**统计区。** 显示四项计数：论文库中已上传的论文总数、工作区数量及其收录论文总数、深度研究联网扩展发现的论文数量、近期条目数量。

## 5.2 上传论文

**操作步骤：**

1. 在首页找到底部的投放区
2. 从文件管理器中拖拽 PDF 文件到投放区，或点击投放区后在弹出的对话框中选择文件
3. 松开鼠标或确认选择后开始上传，投放区显示进度
4. 上传成功后自动跳转至精读页面并开始解析

**约束条件：**

- 仅接受 PDF 格式
- 论文正文文本超过 10 万字符时，软件保留前 3 页与最后 1 页参与解析，以控制单次模型调用的输入规模
- 上传的文件以随机标识符命名后存放于 `uploads` 目录，原文件名记录在数据库中

**异常处理：** 上传失败时投放区下方显示「上传失败，请检查文件格式后重试」，同时右上角弹出提示。此时确认文件确为 PDF 格式且未损坏后重新上传。

## 5.3 精读页面布局

精读页面路径为 `/reader/{论文标识}`，采用三栏布局。

**中栏：PDF 阅读区。** 渲染论文原文。顶部工具栏提供侧边栏开关、专注模式与分析面板开关。

**右栏：分析面板。** 显示解析结果的七个选项卡。默认占页面宽度的 35%。

**分割条。** 中栏与右栏之间是可拖拽的分割条，用于调整分析面板宽度，可调范围为页面宽度的 20% 至 60%。双击分割条恢复默认宽度。分割条获得键盘焦点后，左右方向键以 2% 为步长调整宽度，PageUp 与 PageDown 以 10% 为步长调整，Home 键恢复默认。

面板宽度与展开状态会被记住，下次进入精读页面时保持上次的设置。

## 5.4 PDF 阅读操作

**翻页。** 使用 PageUp 与 PageDown 键翻页，Home 与 End 键跳到首页与末页。

**缩放。** 使用加号键与减号键缩放，数字 0 键重置缩放比例。触控板支持捏合缩放。缩放步进、最小与最大倍率、捏合灵敏度均可在设置页面调整。

**章节跳转。** 在右侧「大纲」选项卡中点击任意章节，PDF 区域跳转到该章节所在位置，并以高亮标记该位置。高亮持续时长默认 3 秒，可在设置页面调整。

**专注模式。** 点击顶部工具栏的放大镜图标进入专注模式。该模式下浏览器进入全屏，隐藏左栏与右栏，仅保留 PDF 阅读区。按 Esc 键或点击右上角的收缩图标退出。

- **删除所选**：弹出确认对话框，提示所选篇数且删除后不可恢复，确认后批量删除

批量操作逐篇独立执行，完成后汇总报告结果。全部成功时提示成功篇数；部分失败时同时提示成功与失败篇数。

# 第 9 章 深度研究

深度研究页面路径为 `/workspace/{工作区标识}/research`，在工作区的论文集合上构建引文图谱并提供跨论文问答。

## 9.1 页面组成

页面左侧为控制面板，右侧上方为图谱画布，右侧下方为跨论文问答区。顶部读数区显示节点数、边数、平均度与子方向数量。

【截图 9-1】深度研究页面完整界面。

## 9.2 启动研究

控制面板列出工作区内的论文及其状态，状态取值包括「已精读」「已速读」「已解析」「已索引 · 待解析」「待解析」「解析失败」「提取中」「分析中」。

面板下方的主按钮显示当前可参与研究的论文构成，形如「开始研究（N 篇本地 + M 篇已扩展）」。点击后流水线开始执行，按钮变为「运行中...」，进度实时显示。

**流水线阶段：**

| 阶段 | 说明 |
|------|------|
| 收集 | 下载工作区论文缺失的全文 |
| 扩展 | 解析参考文献，按配置联网抓取相关文献 |
| 分块 | 将论文全文切分为文本块 |
| 向量化 | 为每个文本块计算向量表示 |
| 速读 | 对未精读的论文做轻量解析，使其获得可解释的图谱关系 |
| 建图 | 计算论文两两关联度，抽取骨架，划分子方向 |
| 持久化 | 将图谱与向量索引写入本地 |

研究运行期间可以离开页面，但完成前不要关闭后端进程。

【截图 9-2】深度研究运行中的进度面板。

## 9.3 图谱画布

图谱以力导向图渲染，节点为论文，边为论文之间的关联关系。

**节点交互。** 点击节点打开详情面板，显示该论文的标题、元数据与在图谱中的位置信息。

**边交互。** 点击边打开边详情面板，说明该关系由哪些通道贡献。边可按通道类型筛选，通道包括主题、研究目的、方法与术语四类。

**图谱统计。** 页面显示的统计信息包括：

- 节点数与边数
- 平均度：每篇论文平均连接的边数，及其与目标密度的对比
- 子方向数量与划分质量指标，该指标越高说明子方向越分明
- 骨架提取结果：从多少候选边中保留了多少条关系边，其中多少条是为保证图谱连通而补充的桥接边
- 权重校准结果：说明是否按本工作区的引用证据自动调整了通道权重，以及调整依据

【截图 9-3】图谱画布，显示节点、边与统计读数。

【截图 9-4】点击节点后打开的论文详情面板。

## 9.4 研究设置

点击「研究设置」打开设置抽屉，可调整本次研究的参数，包括图谱密度等高级设置。修改后需重新运行研究才能生效。

## 9.5 跨论文问答

页面下方的问答区支持在工作区的论文集合上提问。

**检索模式。** 提供三种模式：

| 模式 | 说明 |
|------|------|
| 图谱 | 向量检索、关键词检索与图谱随机游走三路融合，并附加路径解释 |
| 混合 | 稠密向量与关键词检索融合后重排序 |
| 向量 | 仅使用稠密向量检索并重排序 |

**提问步骤：**

1. 选择检索模式
2. 在输入框中输入问题
3. 点击「提问」按钮
4. 检索期间显示「检索中…」
5. 结果显示回答正文、引用来源列表；图谱模式下额外显示图谱路径

**检索调试。** 点击「展开检索调试」查看检索过程的中间结果，再次点击收起。

尚未构建图谱时，问答区提示「构建图谱后可进行跨论文语义检索」。

## 9.6 图谱速读

工作区中存在未精读的论文时，控制面板提供「速读未解读论文」操作。速读只抽取研究目的、方法、数据集、基线与简短总结，消耗的计算量约为完整精读的十分之一到五分之一，目的是让这些论文也能在图谱中获得可解释的关系。

速读在后台执行，可离开页面，完成前不要关闭后端。完成后提示成功与失败篇数，并需要重新点击「开始研究」重建图谱使其生效。

若在设置页面开启了「深度研究时自动图谱速读未解读论文」，则每次深度研究在建图前自动执行速读，无需手动触发。

## 9.7 引用回填

控制面板提供引用回填操作，通过学术检索服务补全论文之间的引用关系。回填在后台执行，完成后显示补全的引用条数、其中链接到本地论文的条数，并自动重建图谱。

## 9.8 清空图谱

点击「清空」按钮，弹出确认对话框，提示将清空该工作区的图谱和向量索引，且不会删除论文文件。确认后执行。

# 第 10 章 系统设置

设置页面路径为 `/settings`，包含三个选项卡。

## 10.1 模型配置

分为「解读模型」与「翻译模型」两组，每组包含接口地址、接口密钥与模型名称三项。

- **解读模型**：用于论文解析、总结等功能
- **翻译模型**：用于选中文本的翻译功能

**密钥显示。** 接口密钥默认以掩码显示，点击「显示」切换为明文，点击「隐藏」恢复掩码。

**高级参数。** 展开「高级参数」可调整：

- 温度：取值 0 至 2，0 为精确、1 为平衡、2 为随机
- 最大输出长度

**连通性测试。** 点击「测试连接」按钮验证参数是否可用。

**配置状态提示。** 配置不完整时，页面顶部显示提示条，分别指出「翻译模型未配置密钥，画词翻译不可用」或「解读模型未配置密钥，论文分析会退回默认配置」。

**保存。** 页面底部固定保存栏，点击「保存配置」提交。保存过程中按钮显示「保存中…」，成功后显示「已保存」。存在未保存修改时离开页面，会弹出确认对话框询问是否放弃修改。

【截图 10-1】设置页面「模型配置」选项卡。

## 10.2 界面与主题

**主题选择。** 提供多套内置主题，默认为深色主题。选择后立即生效。页面同时提供自定义主题编辑器。

**界面字体。** 提供三种预置字体（非衬线、衬线、等宽，中文自动回退），也可在输入框中填写自定义字体名称。该设置仅作用于界面文字，不影响源码展示区域。

**大纲跳转高亮时长。** 控制点击大纲条目跳转后高亮标记的持续时间，默认 3 秒。

**缩放参数。** 可折叠区块，包含四项：

- 每次缩放步进
- 最小缩放倍率
- 最大缩放倍率
- 触控板捏合灵敏度：低（1%）、默认（2%）、高（10%）

【截图 10-2】设置页面「界面与主题」选项卡。

## 10.3 深度研究设置

**向量嵌入模型。** 用于深度研究的文本向量化。提供本地模式与远程服务两类选择。本地模式首次运行需下载模型文件，体积约 2 GB。

**高级参数。** 包含三项：

- 单条输入长度上限：远程模型的单条截断上限。中文约 1 字对应 1 个计量单位，英文约 4 字对应 1 个计量单位
- 硬字符上限：在长度截断之外再加一道字符数上限，取 0 表示关闭。一般保持 0，仅在仍偶发请求失败时设置保守值
- 批大小：本地模式每批编码的条数，显存不足时调小

**论文扩展源。** 决定联网扩展阶段从哪里抓取参考文献。可选择具体的文献服务，或选择「本地（不联网）」。选择本地模式时，联网扩展阶段被直接跳过，图谱仅基于工作区已上传的论文构建。

部分文献服务支持填写邮箱以获得更稳定的访问配额，部分服务需要申请访问凭证。设置项旁标注了各服务的推荐程度与申请方式。

**扩展方向。** 可选择三类扩展方向：

| 方向 | 说明 |
|------|------|
| 反向引用 | 起始论文参考文献列表中的被引文献 |
| 正向引用 | 引用起始论文的后续论文 |
| 相关推荐 | 文献服务给出的语义相关推荐 |

**自动图谱速读。** 开启后，每次深度研究在构建图谱前自动对未精读论文执行一次轻量速读，使其获得可解释的图谱关系。会消耗少量计算额度。关闭时只能手动触发速读。

# 第 12 章 常见问题与故障排除

## 12.1 启动阶段

**问：执行 `./start.sh` 提示端口已被占用。**

答：软件默认使用 8000 端口运行后端、5173 端口运行前端。按提示执行 `lsof -i :端口号` 查看占用进程并终止，或在 `.env` 中修改 `PORT` 变量后重新启动。

**问：前端页面能打开，但所有数据都加载失败。**

答：说明后端未正常启动或跨域许可未通过。先访问 `http://localhost:8000/docs` 确认后端在运行，再检查 `.env` 中的 `FRONTEND_ORIGIN` 是否与实际访问地址一致。

**问：后端启动报数据库错误。**

答：确认项目根目录下 `data` 目录存在且可写。软件启动时会自动创建数据库文件并执行结构迁移。

## 12.2 解析阶段

**问：上传成功但解析一直没有进度。**

答：依次检查三项：设置页面的解读模型是否已填写接口密钥；「测试连接」是否通过；本机能否访问所配置的模型服务地址。

**问：解析中途提示连接中断。**

答：这是前端与后端的事件流连接断开，后台解析任务仍在运行。点击「重新连接」即可继续接收进度，不要点击「重新分析」，否则会重新消耗计算额度。

**问：解析结果中部分字段为空。**

答：软件对论文正文超过 10 万字符的情况会做截断处理，仅保留前 3 页与最后 1 页参与解析。若论文篇幅过长或版式特殊导致文本抽取不完整，可能出现部分字段为空。可尝试点击「重新分析」。

**问：相关论文推荐一直显示搜索中。**

答：相关论文检索在主体解析完成后于后台执行，依赖外部学术检索服务。超时或失败时会显示提示，不影响其他解析结果，点击「重新搜索」重试即可。

## 12.3 划词与标注

**问：选中文本后没有弹出操作气泡。**

答：确认选中的是 PDF 文本层的内容。扫描版 PDF 没有文本层，无法选中文字。

**问：点击翻译提示需要配置。**

答：翻译功能使用「翻译模型」而非「解读模型」，需在设置页面单独填写翻译模型的接口密钥。可与解读模型使用同一套参数。

## 12.4 代码分析

**问：克隆仓库失败。**

答：确认本机能访问该代码托管平台，且仓库地址正确、仓库为公开状态。私有仓库需要凭证，软件不处理此情况。

**问：代码选项卡显示未找到源码地址。**

答：软件通过匹配论文正文中的代码托管平台链接来识别仓库。论文未提供链接，或链接以图片形式出现时无法识别。可点击「重新查找」再次尝试。

## 12.5 深度研究

**问：点击开始研究后提示论文数量不足。**

答：深度研究需要在论文之间建立关系，工作区中至少需要两篇论文。

**问：图谱边太多或太少。**

答：图谱密度由「目标平均度」控制，表示每篇论文平均连接的边数。在研究设置中调整该参数后重新运行研究。

**问：本地向量模型下载缓慢。**

答：本地模式首次运行需下载约 2 GB 的模型文件。可改用远程向量服务，在设置页面的「深度研究」选项卡中切换。

**问：向量化阶段请求失败。**

答：远程向量服务对单次输入长度有限制。在「深度研究」设置中调低「单条输入长度上限」，必要时设置「硬字符上限」为保守值。本地模式下显存不足时调小「批大小」。

**问：不希望联网抓取文献。**

答：在「深度研究」设置的「论文扩展源」中选择「本地（不联网）」，联网扩展阶段会被跳过，图谱仅基于工作区已上传的论文构建。

## 12.6 数据管理

**问：论文文件存放在哪里。**

答：上传的 PDF 存放于项目根目录的 `uploads` 目录，以随机标识符命名。克隆的代码仓库存放于 `code_downloads` 目录，按论文标识分子目录。数据库文件位于 `data` 目录。

**问：删除论文后数据是否可恢复。**

答：不可恢复。批量删除前会弹出确认对话框提示删除后不可恢复。

**问：如何备份。**

答：完整备份 `data`、`uploads` 与 `code_downloads` 三个目录即可保留全部数据。

| `/api/annotations` | 标注 | 划词标注增删查 |
| `/api/tags` | 标签 | 标签与论文标签关联管理 |
| `/api/agent-tools` | 工具链 | 研究工作流的工具接口 |

另有两类非 HTTP 接口：

- WebSocket 终端接口：为代码分析页面的终端面板提供伪终端会话
- SSE 日志流接口：向前端推送后端运行日志

后端启动后可访问 `http://localhost:8000/docs` 查看完整的接口文档。
