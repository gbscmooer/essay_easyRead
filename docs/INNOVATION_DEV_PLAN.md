# 优秀毕设创新开发计划

## 本次迭代范围

1. 工作区自适应阅读路径
   - 输入：工作区论文集合、最新研究图谱、论文画像。
   - 输出：按阶段分组的阅读路径、每篇论文的推荐理由、依赖边、覆盖统计。
   - 算法：引用边建立前置关系，语义边和重要性分数作为排序权重，年份作为兜底顺序。

2. 工作区综述与对比矩阵
   - 输入：工作区论文画像。
   - 输出：研究综述草稿、论文对比矩阵、任务/方法/数据集/局限性汇总。
   - 算法：复用结构化分析与速读摘要字段，按研究问题、方法、实验、代码映射聚合。

3. RAG/Agent 工具链整理
   - 保留 HTTP Agent Tools 与 MCP stdio 服务。
   - 保留评测脚本和测试，覆盖检索模式与 SSE 稳定性改动。

## 后端改动

- 新增 `services/workspace_planner.py`。
- 新增 `GET /api/workspaces/{workspace_id}/reading-plan`。
- 新增 `GET /api/workspaces/{workspace_id}/survey`。
- 新增响应 schema，保持 `services/` 与 `routers/` 解耦。

## 前端改动

- 在工作区详情页接入阅读路径和综述矩阵。
- 新增工作区智能面板组件，展示阶段路径、覆盖统计和矩阵。
- API 类型与后端 schema 对齐。

## 验收

- 后端单测覆盖：
  - 有研究图谱时，阅读路径按引用/年份/重要性排序。
  - 无研究图谱时，阅读路径可使用年份与读取状态兜底。
  - 综述矩阵可从 full/digest/metadata 三层画像生成。
- 前端构建通过。
- 文档更新 `document.md` 和 `README.md`。
- 提交前阅读 `docs/commit_regular.md`，同步版本信息并打 tag。

## 后续保留项

- 公式到代码双向映射需要稳定的公式抽取来源，不纳入本次提交。
- 3D 图谱切换需要新增依赖和视觉验收，不纳入本次提交。
